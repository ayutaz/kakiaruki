# カキアルキ

**描いた線が、歩きかたを覚える。**

### ▶ 遊ぶ: **<https://ayutaz.github.io/kakiaruki/>**

[![Deploy to GitHub Pages](https://github.com/ayutaz/kakiaruki/actions/workflows/deploy.yml/badge.svg)](https://github.com/ayutaz/kakiaruki/actions/workflows/deploy.yml)

キャンバスに一筆で生きものの骨格を描くと、その形のまま「関節の動かし方」を進化で探します。世代が進むにつれて、無秩序にもがいていた個体が、歩いたり跳ねたり転がったりして前へ進むようになります。

**形を決めるのはあなたです。** 進化計算が探すのは、その形をどう動かすかだけです。

## 遊びかた

1. キャンバスをドラッグして、一筆で骨格を描く。黄色が骨、白い丸が関節です。
2. **線をなぞって戻る**と、そこから枝が生えます。胴 → 肩まで戻る → 腕、の順で人型も描けます。
3. 「この形で学習する」を押す。数秒〜10秒ほどで学習が終わります。
4. 古い世代と新しい世代が、同じ地面に並んで走ります。**暗い線が古く、明るい線が新しい世代**です。
5. 世代スライダー、速さ、並べる世代数を変えて見比べる。気が済んだら描き直す。

キーボードだけでも操作できます。**Ctrl+Z** で骨を1本戻す、**Backspace** で全部消す、**Enter** で学習開始。

## 仕組み

```text
一筆の点列
  → 正規化・等間隔サンプリング
  → 折れ曲がりと「戻り線」を見つけて、節点と骨の木にする
  → 骨をカプセル剛体、節点を回転関節にする
  → 同じ形の32個体に、違う関節パラメータを与える
  → 6秒間の物理シミュレーションで、どれだけ前へ進めたかを測る
  → 選択・交叉・突然変異で次の世代をつくる
```

関節は、周期関数（振幅・位相・バイアス・全体周波数）で目標角度を決め、PD制御でモーター速度に変えています。進化するのはこのパラメータだけで、**形は一切変わりません**。

物理は固定タイムステップ（1/60秒・4サブステップ）で、32個体を**1つの物理ワールドの中の別レーン**で同時に評価します。個体どうしは衝突しません。

乱数はシード付きなので、同じシードなら同じ結果が再現します。

## 制約

- デスクトップの **Chromium系ブラウザ**を対象にしています。mobileとSafariは動作保証の対象外です。
- **輪（閉ループ）と自己交差は、まだ扱えません。** 勝手に別の形へ変えず、理由を表示して描き直しをお願いします。
- 骨は最大20本です。長すぎる線は、骨を太くして収めます。それでも収まらないものだけ拒否します。
- 学習中はブラウザが1世代ごとに一瞬止まります（1世代あたり最大0.5秒）。進捗は画面に出ます。
- **体験としての品質確認は終わっていません。** 技術的な検証を通した段階の公開です。

## ローカルで動かす

Node.js 24以上、npm 11以上が必要です。

```bash
npm ci
npm run dev     # http://127.0.0.1:5173/
```

公開版と同じものが `http://127.0.0.1:5173/` で開きます。`/bench/` 以下には開発用の計測ページがありますが、公開対象ではありません。

```bash
npm run verify  # 自動試験 + 型検査 + 本番ビルド
```

## 技術スタック

| | |
|---|---|
| 物理 | [Phaser Box2D](https://www.npmjs.com/package/phaser-box2d) 1.1.0（Box2D v3のJS移植） |
| 言語 | TypeScript 7（strict） |
| ビルド | Vite 8 / 試験は Vitest 5 |
| 描画 | Canvas 2D |

物理・進化計算・一筆の変換は、描画フレームワークから独立した純粋なTypeScriptとして書いています。製品画面はPhaserを読み込みません（production build は 217 kB / gzip 62 kB）。

## 原作との関係

このプロジェクトは、公開されているゲーム **『一筆進化』**（Godot製）の**体験を参考にした、独立した実装**です。

- 原作のソースコード、アセット、非公開パラメータには**アクセスしていません**。
- 遺伝子の形式、Fitness、選択方式、物理設定は**すべて独自の再現案**です。「同じアルゴリズム」ではありません。
- 画像・音・フォントファイルを**1つも同梱していません**。描画はすべてCanvas 2D、文字はOS標準フォントです。原作の画像・音・文章・画面配置はコピーしていません。

原作: [一筆進化 - unityroom](https://unityroom.com/games/one-stroke-evo)
