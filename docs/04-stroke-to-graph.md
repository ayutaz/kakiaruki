# 一筆入力から物理グラフへの変換

## 1. この機能が最大の実装難所

GAより難しいのは、どのような描線でも有限で安定した物理構造へ変換することです。生のPointer点をすべてBodyにすると、数百の短い骨と関節ができ、物理が不安定になります。

目標は次の変換です。

```text
Raw Stroke
  -> 正規化された点列
  -> 位相を保つStrokeGraph
  -> 制約済みCreatureGraph
  -> Body / Joint記述
```

## 2. データモデル案

```text
StrokePoint
  x, y, time, pressure?

GraphNode
  id, position, kind

GraphEdge
  id, nodeA, nodeB, polyline, length

CreatureGraph
  nodes[], edges[], rootNodeId, metadata
```

重要な不変条件は次です。

- Node IDとEdge IDは一意。
- Edgeの両端Nodeが必ず存在する。
- 自己ループEdgeは、明示的に許可するまでは作らない。
- Edge長は最小値以上、最大値以下。
- Node次数、Edge数、総延長に上限がある。
- すべての座標は有限値で、キャンバス内へ正規化される。
- MVPではグラフが1つの連結成分である。

## 3. 推奨パイプライン

### Step 1: 入力取得

- `pointerdown`でStrokeを開始する。
- `pointermove`で、前回点から最小距離以上動いた場合だけ記録する。
- `pointerup`またはキャンセルで確定する。
- Pointer captureを使い、キャンバス外へ出ても終了状態を失わない。
- 点数、描画時間、キャンバス外座標に上限を設ける。

### Step 2: 正規化と等間隔再サンプリング

デバイスごとにPointerイベント密度が異なるため、一定距離間隔へ再サンプリングします。ここでは形状を過度に単純化せず、戻り線や交差の情報を残します。

### Step 3: 位相イベントの検出

次を先に検出します。

- 既存Node付近への再接近。
- 既存Edge付近を逆方向になぞる「戻り」。
- 既存Edgeとの自己交差。
- 一定角度以上の折れ曲がり。
- 始点付近へ戻る閉路候補。

**RDP簡略化を全点列へ先に適用しない**ことが重要です。全体を先に簡略化すると、枝を作るための戻り線や近接イベントを消すおそれがあります。位相を分割した後、各Edgeの内部形状へ局所的に簡略化を適用します。

### Step 4: NodeとEdgeへの分割

始点、終点、戻り点、分岐点、採用する交点をNodeとし、その間をEdgeにします。近すぎるNodeは距離閾値で統合しますが、統合後にEdgeがゼロ長にならないことを再検証します。

### Step 5: 物理用の制約

初期提案値です。実測前のため決定値ではありません。

| 制約 | 初期提案 |
|---|---:|
| 最大Edge数 | 16 |
| Nodeの最大次数 | 4 |
| 最小骨長 | 画面短辺の2% |
| 最大骨長 | 画面短辺の20% |
| 最大総延長 | 画面短辺の150% |
| カプセル半径 | 骨長と独立した範囲で固定または段階選択 |

長すぎるEdgeは分割し、短すぎるEdgeは隣接Edgeへ統合します。上限を超えた場合は、黙って別形状へ変えず、どの制約に触れたかをUIで表示します。

## 4. 枝分かれの扱い

原作では戻るようになぞることで枝を作れます。MVPでは次の明示的な規則を提案します。

1. 現在点が既存Edgeの許容帯へ入る。
2. 数サンプルにわたって既存Edgeと逆向きに進む。
3. 既存NodeまたはEdge上の投影点へ吸着する。
4. そこから別方向へ離れた時点を分岐開始とする。

単なる線の近接を分岐と誤認しないため、距離だけでなく進行方向と継続サンプル数を使います。「枝を戻す」はグラフ確定後のEdge単位Undoとして実装すると、Pointer点単位Undoより理解しやすくなります。

## 5. 自己交差と閉ループ

### MVPでの提案

- 戻り線による枝分かれは対応する。
- 任意の交差は見た目だけ交差させるか、Node化するかをUI仕様として明示する。
- 始点と終点が近い場合の単純閉ループは、P4以降の安定性試験後に有効化する。
- 多重ループ、非常に短い閉路、重複Edgeは拒否または修正候補として表示する。

閉ループは物理ソルバに循環拘束を作るため、木構造より不安定になりやすいです。カプセル長、質量比、サブステップ数、角度limitを組み合わせた試験が必要です。

## 6. Graphから物理構造への変換

- Edgeごとに、その両端を中心線とするカプセルBodyを作る。
- Edgeの中点をBody位置、方向をBody角度、長さをカプセル中心線長とする。
- 共有Nodeに接続するBody同士をRevolute Jointで結ぶ。
- 接続Body間の衝突は原則無効化する。
- 次数3以上のNodeでは、基準Bodyを1つ選び、残りを基準Bodyへ接続する。
- rootは重心に近いNodeまたは最長Edge周辺から決め、ID順に依存しない安定した規則にする。

## 7. 受入試験用の代表形状

| 形状 | 期待 |
|---|---|
| 直線 | 1 Body、Jointなし |
| L字 | 2 Body、1 Joint |
| 人型相当の木 | 複数枝、単一連結成分 |
| 戻り線を含むY字 | 分岐Nodeの次数3 |
| 単純な輪 | P4までは明示的に保留または安全に拒否 |
| 小さなジグザグ | 上限内へ簡略化される |
| 同一点を連打 | ゼロ長Edgeを作らない |
| 極端な長線 | 上限で分割または拒否理由を返す |
| NaN相当の不正入力 | 例外で全体を壊さずValidation error |
